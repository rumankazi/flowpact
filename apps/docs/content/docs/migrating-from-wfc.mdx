---
title: Migrating from wfc
description: flowpact was called wfc before 0.2.0. What changed, and how to move a repository over in one command.
---

flowpact was called **wfc** up to 0.1.x. Version 0.2.0 renamed the tool; the engine, rules and contracts are the same.

## What changed

| | wfc (0.1.x) | flowpact (0.2.0+) |
| --- | --- | --- |
| npm package | `workflow-contracts` | `flowpact` |
| Command | `wfc` | `flowpact` |
| GitHub Action | `rumankazi/wfc@v0` | `rumankazi/flowpact@v0` |
| Rule codes | `WFC101` … `WFC903` | `FP101` … `FP903` (same numbers) |
| Config | `.github/workflow-contracts/wfc.config.yml` | `.github/flowpact/flowpact.config.yml` |
| Contracts | `.github/workflow-contracts/{workflows,actions}/` | `.github/flowpact/contracts/{workflows,actions}/` |
| Environment variables | `WFC_DEBUG`, `WFC_NO_HYPERLINKS` | `FLOWPACT_DEBUG`, `FLOWPACT_NO_HYPERLINKS` |
| Contract drift artifact | `wfc-contracts` | `flowpact-contracts` |
| Docs and schemas | `rumankazi.github.io/wfc` | `rumankazi.github.io/flowpact` |

## Move a repository over

<Steps>
<Step>
### Install flowpact

```sh
npm uninstall --global workflow-contracts
npm install --global flowpact
```

In `package.json`, replace the `workflow-contracts` dev dependency with `flowpact`, and `wfc` in scripts with
`flowpact`.
</Step>
<Step>
### Move the config and contracts

```sh
flowpact migrate
```

It moves the config and the contracts to `.github/flowpact/`, renames `WFC` codes in the config (`rules`, `overrides`)
to `FP`, and updates the schema URLs. Until you run it, flowpact still reads the old location and reports
[`FP904`](/docs/rules/fp904) as a reminder.
</Step>
<Step>
### Update the workflow

```yaml
- uses: rumankazi/flowpact@v0   # was rumankazi/wfc@v0
```

GitHub redirects the old repository name, so `rumankazi/wfc@v0` keeps working for now, but switch to the new name. If a
later step downloads the contract drift artifact by name, use `flowpact-contracts`.
</Step>
<Step>
### Check and commit

```sh
flowpact check
git add -A .github && git commit -m "chore: migrate from wfc to flowpact"
```
</Step>
</Steps>

## Rule codes

Old codes are not accepted any more: `--only WFC401`, `flowpact explain WFC401` or `rules: { WFC104: off }` fail with
a suggestion of the new code (`did you mean FP401?`). `flowpact migrate` renames them in the config; replace them by
hand in scripts and documentation. Rule **names** (`unused-input`, …) did not change, so configs that use names keep
working.

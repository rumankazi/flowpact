## Why it matters

Dynamic matrices (`fromJSON(...)`) hide the same empty-value failure mode as static ones, but no tool can see it.

## How to fix

Declare the keys in the config (`matrixShapes: \{ "\<workflow\>#\<job\>": \{ keys: [os, config] \} \}`) so wfc can verify reads, prefer a static matrix, or validate the generated JSON in the job that produces it.

## Configure

Change the severity (or turn the rule off) in `.github/workflow-contracts/wfc.config.yml`, by code or by name:

```yaml title=".github/workflow-contracts/wfc.config.yml"
rules:
  WFC403: off
  # or: dynamic-matrix-unverified: error
```

## Why it matters

The read evaluates to an empty string. This is typically a typo in the `echo "name=value" \>\> $GITHUB_OUTPUT` line.

## How to fix

Write the output in the step (`echo "\<name\>=\<value\>" \>\> "$GITHUB_OUTPUT"`) or read the name it actually writes.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
- id: meta
  run: echo "ver=1.2.3" >> "$GITHUB_OUTPUT"
...
version: ${{ steps.meta.outputs.version }}
```

</Tab>
<Tab value="Fixed">

```yaml
- id: meta
  run: echo "version=1.2.3" >> "$GITHUB_OUTPUT"
```

## Why it matters

The `needs` context only contains direct dependencies. Without the edge, the value is empty and the jobs may also run in parallel, so even a fixed name would race.

## How to fix

Add the job to `needs:` (it is fine to list transitive dependencies explicitly).

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
deploy:
  needs: test
  run: deploy ${{ needs.build.outputs.version }}
```

</Tab>
<Tab value="Fixed">

```yaml
deploy:
  needs: [build, test]
```

</Tab>
</Tabs>

| `WFC301` | `undefined-output-ref` | Outputs | 🔴 error |

## Why it matters

Undefined outputs evaluate to an empty string. Downstream jobs then run with missing versions, tags or flags.

## How to fix

Fix the output name, declare the output on the job/workflow/action, or reference the right job or step.

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
jobs:
  build:
    outputs:
      version: ${{ steps.meta.outputs.version }}
  deploy:
    needs: build
    run: deploy ${{ needs.build.outputs.vesion }}
```

</Tab>
<Tab value="Fixed">

```yaml
    run: deploy ${{ needs.build.outputs.version }}
```

</Tab>
</Tabs>

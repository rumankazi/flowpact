## Why it matters

Without a locked contract, changes to its interface and wiring are not visible in review and cannot be checked.

## How to fix

Run `wfc generate` and commit the updated contracts. In CI, the wfc action (check mode) attaches the regenerated contracts and a `git apply`-able patch to the run — see its job summary.

## Configure

Change the severity (or turn the rule off) in `.github/workflow-contracts/wfc.config.yml`, by code or by name:

```yaml title=".github/workflow-contracts/wfc.config.yml"
rules:
  WFC801: off
  # or: contract-missing: error
```

Explain it in the terminal:

```sh
wfc explain WFC801
```

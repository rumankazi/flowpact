## Why it matters

An unreadable contract cannot be compared, so drift and breaking changes go unnoticed.

## How to fix

Contracts are generated: resolve the merge by running `wfc generate` instead of editing the file.

## Configure

Change the severity (or turn the rule off) in `.github/workflow-contracts/wfc.config.yml`, by code or by name:

```yaml title=".github/workflow-contracts/wfc.config.yml"

  WFC805: off
  # or: contract-invalid: error
```

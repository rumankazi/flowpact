## Why it matters

GitHub rejects the call ("Invalid secret … is not defined in the referenced workflow").

## How to fix

Declare the secret under `on.workflow_call.secrets` in the callee, fix the name, or remove it.

## Configure

Change the severity (or turn the rule off) in `.github/workflow-contracts/wfc.config.yml`, by code or by name:

```yaml title=".github/workflow-contracts/wfc.config.yml"

  WFC202: off
```

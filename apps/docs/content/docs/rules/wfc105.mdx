## Why it matters

When a caller omits an optional input that has no default, GitHub substitutes an empty string. Conditions then take the "false" branch silently, so jobs or steps are skipped and the run is still green.

## How to fix

Give the input an explicit `default`, make it `required: true`, or compare explicitly (`inputs.x != ''`).

## Example

<Tabs items={["Problem", "Fixed"]}>
<Tab value="Problem">

```yaml
inputs:
  variant: { type: string, required: false }
...
if: inputs.variant == 'gpu'
```

</Tab>
<Tab value="Fixed">

```yaml
inputs:
  variant: { type: string, required: false, default: cpu }
```

</Tab>
</Tabs>
